## Submission format (verified from GEMSDOE family research pages)

- Single-band GeoTIFF (.tif), or .zip containing one GeoTIFF
- Must match sample_submission.tif CRS / shape / geotransform exactly
- Verified grid (GEMSDOE25/GEMSDOE36 research pages): EPSG:32611, 3730 × 3292 px (12,279,160 cells), ~5.17M valid footprint cells
- Values must be finite and in **[0, 1]** (portal rejects "Predicted values must be in range [0, 1]")
- No NaN inside the footprint (use `-zeros` encoding: fill outside-footprint with 0)
- Float32, one band

## Metric (verified)

DTI = Tversky index, alpha = 0.2, beta = 0.8, 300 m triangular kernel, computed on a spatially-blocked holdout (hide whole fault segments + buffer, recover from visible faults only).

DTI = TP / (TP + 0.2·FN + 0.8·FP). Because beta (0.8) > alpha (0.2), false positives are penalized 4× false negatives → **sparse, confident dots beat dense maps**.

## Why GEMSDOE32 scored 0.2778 (PhD synthesis, GEMSDOE36 research)

Under DTI (α=0.2, β=0.8, 300 m kernel), a dot improves DTI iff marginal weighted recall ΔTPw > 0.2·DTI (≈0.0556 at 0.2778). Every focus-9 leader re-thins the H19-5 ridge skeleton (0.1922 owner-reported):
- `d=2.8` dotting cut false positives 3× while preserving ~74% along-trace kernel bridge credit (+0.0678)
- `B2` excised 6,436 near-catalogue detector-echo dots at 0 < d_cat ≤ 2 px (+0.0178)

But H19-5 covers only ~30–36% of hidden faults, so re-thinning it asymptotes below ~0.295. To surpass 0.2778 toward public leaders (0.3195 / 0.4413 / 0.4437): close the 1 m LiDAR gap with 10 m 3DEP, detect blind range-front uplift via fluvial χ/ksn + hydrothermal upflow, add Stage-2 spatial context, and add off-catalogue pre-Quaternary bedrock faults + ASTER TIR alteration.
