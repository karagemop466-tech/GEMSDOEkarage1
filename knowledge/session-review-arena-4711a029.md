## B2 explanation and limits

The official metric specification (source register [A1–A4](official-sources-verified-2026-10-29.md)) defines the distance-weighted Tversky objective with α=0.2, β=0.8 and triangular radius 300 m. Missed truth receives four times the coefficient of false-positive mass. If deleting predictions removes false-positive weighted mass `c`, but loses weighted true coverage `L`, deletion improves DTI only when `α T c > L (α F + β G + ε)` for pooled weighted true positives `T`, false-positive mass `F`, hidden truth count `G` and stabilizer `ε`. The inequality clarifies the possible mechanism; it cannot establish that B2's removed pixels were low-yield. Existing catalogue pixels are masked pixel-exactly per the staff clarification; a surrounding collar is not a free scoring zone.

Thus the most defensible answer is: **a result above the reported 0.2778 is possible, but this repository cannot currently establish or estimate one.** No numerical projection is supplied. The GEMSDOE32 value itself lacks an organizer receipt tied to the TIFF hash.
