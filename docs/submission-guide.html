How to submit — only after every gate passes

Nothing is approved for upload today.

There is no authorized download button. This guide is for a future selected artifact, not permission to upload a historical TIFF.

  1. Read the executive decision. Scientific promotion requires complete holdout, canary, uniqueness, provenance, and saved-byte checks. A separate selector must confirm an available weekly slot using the authenticated submission screen.
  2. Download only the exact approved single-band GeoTIFF (or ZIP containing only that TIFF), with its unique name, SHA-256 and note. Do not rename an old raster to imply uniqueness.
  3. The automated saved-byte validator must confirm float32, finite values everywhere in [0,1], and exact template CRS, shape and transform. Do not substitute -9999, infinities or NaNs for valid prediction values.
  4. Open the official competition, review its current rules and submission cap, then choose New submission.
  5. Choose File to submit, select the authorized TIFF or ZIP, and paste the recorded note (at most 140 characters). This repository does not automate portal uploads.
  6. Save the organizer’s submission-page receipt and the artifact SHA-256. Only then label the result ORGANIZER-CONFIRMED. A HOLDOUT-DTI measurement is not a leaderboard score.

Range error prevention

“Predicted values must be in range [0, 1]” requires checking saved TIFF values, not merely an in-memory array. A finite zero-outside artifact is the project’s defensive export policy; the authenticated official format and template remain authoritative. A passing format check alone never proves high performance or uniqueness.
