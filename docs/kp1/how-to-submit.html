Steps

  1. Download the GeoTIFF (or the ZIP containing exactly one GeoTIFF) using the buttons above.
  2. Open the DrivenData submission page.
  3. Choose File to submit → the downloaded .tif (or .zip).
  4. Paste the name karage1-kp1-ttca-springalter-far-conduit-32000-20261031 and the note KP1 thermo-tectonic conduit alignment: multi-field edge+scarp+spring+Th/K consensus, >=2px off catalogue, 4px spacing, 32k dots (the portal truncates notes at 140 characters; this one is 132).
  5. Submit. The weekly-slot counter on the submission page is the only authority on how many slots remain.

Why the portal will accept the format

The organizer requires (competition page 967): EPSG:32611, 100 m, the same bounds as the training data, null or NaN outside the bounds, a single 32-bit float band, and values between 0 and 1. The saved bytes pass every one of these checks on disk — see the gate receipt kp1_release_gate.json and the writer receipt next to the file.

Earlier portal rejections in this project returned “Predicted values must be in range [0, 1]”. That is why this file is written all-finite with exact zeros outside the footprint (the stricter of the two policies the organizer permits) and the range is asserted on the re-read bytes, not on the in-memory array.

What to do after submitting

Record the returned score and the submission ID next to the file's SHA-256. That receipt is the only thing that can turn this page's projection into an organizer-confirmed number, and it is what the next session should compare against.
