Where every number comes from

Official

  • Competition page — submission format, scoring formula, rules on external data.
  • Evaluation page — the DTI definition used throughout: k(d) = max(1 − d/300 m, 0), alpha = 0.2, beta = 0.8, single-band float32 GeoTIFF in EPSG:32611 with values in [0, 1].
  • USGS Quaternary fault catalogue — the source of the training labels.

Data used (pinned by SHA-256 in registry/data_manifest.json)

  • training_features.tif — 19 bands, the competition's own feature stack.
  • existing_faults.tif / labels.tif — byte-identical; 60,988 fault cells inside the footprint. That identity is one of the flagged irregularities.
  • sample_submission.tif — defines the grid, CRS, transform and scored footprint.
  • derived_sgmc_faults_100m_u8.tif — state geological map compilation, used only as an independent off-catalogue inventory, never as a feature.

  • kp1_metric_analysis.json — the arithmetic behind "why 0.2778".
  • kp1_exp2_external.json — the external-truth instrument, four arms, leakage canary.
  • kp1_exp3_comparison.json — candidate versus matched random, block bootstrap.

What this site cannot tell you

There is no organizer receipt for any score quoted here. The nine leaderboard values are user-reported, the candidate's value is a projection, and both are labelled as such wherever they appear. A projection is not a score.
