SUBMISSION PROCEDURE — DRIVENDATA DOE GEMS PRIZE

How to submit a GeoTIFF
Step by step, no manual inspection needed.

The competition accepts a single-band GeoTIFF (.tif) or a .zip containing one GeoTIFF. It must match the submission format's CRS, shape, and geotransform (EPSG:32611, 3730×3292, 100 m, transform (100, 0, 243350, 0, -100, 4508550)). Values must be in [0,1]. This page walks you through the exact steps.

STEP 3 — UPLOAD TO DRIVENDATA

Portal submission steps

When a lane is assigned, a holdout DTI clears, and the selector approves a slot, follow these steps.

  1. Go to the competition submission page: DrivenData DOE GEMS submissions ↗ (requires DrivenData login).
  2. Click "New submission" → "File to submit" and choose the GeoTIFF (or the one-TIFF ZIP).
  3. Enter the note (above, ≤140 characters) in the "Note (optional)" field.
  4. Submit. The portal validates CRS, shape, geotransform, and value range. If you see Predicted values must be in range [0, 1], the file contains out-of-range or non-finite values — regenerate with all-finite [0,1] values and 0 outside the footprint.
  5. Check the receipt. Confirm the portal accepted the file. A local validator PASS is not organizer acceptance.
Range-error prevention: The GSE TIF was written with an all-finite, [0,1]-clipped, zero-outside-footprint policy to avoid the earlier portal range rejection. Every pixel inside the footprint is finite and in [0,1]; every pixel outside is exactly 0.
