5. Irregularities for owner review

  1. Holdout design biases against the competition's target. The holdout's truth is mapped catalogue segments. A file that avoids the catalogue (as the competition rewards) scores near zero by construction. The champion scored 0.0047, below the random floor 0.0446. Fix: compute the apron from visible faults only (done in Arm B), or add a truth set the holdout cannot leak. The vendored template is unchanged; this is a template-level decision.
  2. Lattice rule is saturated. The 70% / 3 px rule fails random dots (99.9%). The witness covers 99.87% of the footprint in 3 px disks. The official rules contain no such rule (problem page, verified this session).
  3. Portal error "Predicted values must be in range [0, 1]" is not reproduced. Every local raster that was checked is finite and in [0, 1]. We cannot tell whether NaN-outside rasters cause it. The writer uses all-finite zeros outside the footprint.
  4. Known forensic error. The 0.2778 note describes GEMSDOE28 as "parent minus a 1-pixel collar". The pinned file is not a collar (16,237 removed, 9,807 added).
  5. Identical masks. GEMSDOE25 and GEMSDOE30 have identical dot masks (verified).
  6. Dense archived raster. archive/prototype/.../hunq1 has 3.94 million dots. Almost any dot lies within 3 px of it, so the "100%" overlap is an artifact, not a copy. The strongest overlap with a submission-sized raster is 19.5%.
  7. Restore limits. The GitHub API was rate-limited, so the 'scored' data group could not be restored. The 13GEMSDOE witness was fetched from the pinned commit's codeload archive and matched its SHA-256.
  8. Budget. Two of three experiments used. No slot was spent.

6. What would change the verdict

  1. An owner decision on the lattice rule (official rules do not contain it).
  2. A holdout whose truth is not mapped catalogue, or a validated calibration to the organizer score. Without one, no estimate is possible.
  3. A candidate that beats the matched random floor on the holdout-faithful arm, with a leakage canary AUC below 0.90 for every feature.
