Why GEMSDOE32 B2 leads this list

0.2778 is USER-REPORTED / UNVERIFIED, not an organizer receipt in this repository. The saved-byte lineage audit says B2 is GEMSDOE25's dot set with 6,436 catalogue-adjacent dots removed and none added. In this task, removing predictions near already mapped traces plausibly reduces false positives while retaining candidates away from mapped traces. This is a plausible explanation, not a causal proof: the scores are unverified, the files are highly related, and the local catalogue-recovery holdout does not reproduce their ordering. Further thinning alone is not a scientifically supported route to a higher score.

Can a score above 0.2778 be achieved? Possibly, but there is no validated evidence here that it has been. The necessary path is a distinct off-catalogue geological signal that beats a frozen, comparable spatial holdout and survives leakage, uniqueness and format checks. Do not call a projection or catalogue HOLDOUT-DTI a leaderboard score.
