THE B2 QUESTION

Why did GEMSDOE32 h33-h33-2-b2 report 0.2778, and can we beat it?

What is measured

On the audited mirrored grid, GEMSDOE32 B2 is exactly the GEMSDOE25 dotted-h19-5-d2-8 mask with 6,436 dots removed — every dot within the closed 2 px disk of the mirrored known-fault catalogue — and no dots added (37,654 dots remain). GEMSDOE25 and GEMSDOE30 share the same positive-pixel mask; GEMSDOE31 is the 1 px collar variant; GEMSDOE36 is a strict superset of B2 plus 1,200 dots.

Why thinning helps (mechanism, not a proven cause)

The published metric is a distance-weighted Tversky index, DTI = T / (T + 0.2·F + 0.8·(G − T)), with a 300 m triangular kernel. Known catalogue faults are masked from the scored truth (DrivenData staff clarification). A dot that sits within 300 m of a known fault but farther than 300 m from every hidden fault earns no true-positive credit and a full unit of false-positive cost. Removing such dots therefore raises the ratio. The reported sequence (parent → 1 px collar → 2 px collar → superset) is consistent with that mechanism, but the receipt is absent, so the causal claim is not proven.

Can a new result beat 0.2778?

Possible in principle; not established here. The measured opportunity is that all nine sites are one field dotted differently, and the winner is simply the most aggressively collared. Two levers remain untested by this repository: (1) a full 3 px (300 m) collar that removes every dot capable of earning false-positive cost from a masked known fault, and (2) a genuinely different posterior field. Lane H-K1-SEISMIC-PROX uses official band 10, never used by the repo's 58-channel stack, together with the 3 px collar. No leaderboard estimate is produced, because the hidden labels are unavailable.

HOW TO SUBMIT

Exactly how to submit a file to the competition

  1. Sign in at the competition page and open the Submit / leaderboard tab.
  2. Click New submission.
  3. Under File to submit, choose the single-band GeoTIFF (.tif) or a .zip containing exactly one GeoTIFF.
  4. The file must match the submission format's CRS (EPSG:32611), shape (3730 × 3292) and geotransform (100 m, unrotated). Values inside the footprint must be finite and in [0, 1]; outside the footprint must be null or NaN.
  5. Give it a unique name and a short note (≤ 140 characters), e.g. clustering with k=25.
  6. Confirm. The portal returns an error if any predicted value is outside [0, 1].
Common failure: “Predicted values must be in range [0, 1]”. This happens when the file contains NaN/Inf inside the footprint or values > 1. The candidate on this page is all-finite and binary (0/1), so it does not trip that check — but that only means it is format-valid, not that it is approved.
