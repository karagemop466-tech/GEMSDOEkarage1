01 MEDIUM BENEFIT · MEDIUM COST

Multi-catchment bedrock-incision coherence

From official USGS 3DEP elevation plus hydrography, derive channel networks, drainage area, longitudinal profiles, knickzones and cross-valley asymmetry. Look for repeatable responses across neighboring catchments, not an isolated DEM edge.

Off-catalogue rationale: buried or degraded structures may perturb several channels where a scarp is absent.
Confounders: lithology, base-level change, capture, alluvial fans, dams and incision lag. USGS 3DEP / 3DHP program links exist; exact tile coverage, versions and payloads were not checked. No catchment graph feature was found in the screened modules.
02 LOW–MEDIUM BENEFIT · HIGH COST

Focal-mechanism-consistent microseismic lineaments

Use USGS event locations, moment-tensor nodal planes, uncertainty and local strain orientation; test spatially coherent event families whose mechanisms support a structural corridor.

Off-catalogue rationale: a recently active segment can be seismogenic without a clear mapped surface trace.
Novelty boundary: the existing Walker Lane feature uses strain × microseismicity; this adds mechanism-orientation coherence, not event density. Confounders: sparse mechanisms, location error, aftershocks and induced seismicity. ComCat is an official source; footprint coverage was not checked.
03 LOW / NARROW BENEFIT · VERY HIGH COST

Persistent InSAR deformation discontinuities

Use public Sentinel-1 interferograms or time-series displacement, coherence masks, viewing geometry and multi-epoch displacement gradients; require persistence across independent acquisitions.

Off-catalogue rationale: a currently creeping or repeatedly deforming structure beneath alluvium may lack surface expression; quiet faults will not be detected.
Confounders: atmospheric delay, vegetation, groundwater subsidence, seasonal moisture, unwrapping and geometry. ASF DAAC is an official access route; study-area scenes, processing product and temporal coverage were not checked.

Before any experiment: obtain an explicit lane and canonical-template assignment, authenticate and hash the source payload, freeze the common baseline, test each feature alone for leakage, and apply the full two-phase literal registry gate. No shared-template holdout or slot was run here.
