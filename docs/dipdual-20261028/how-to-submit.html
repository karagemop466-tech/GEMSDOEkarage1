Why you previously got “Predicted values must be in range [0, 1]”

training_features.tif contains raw float32 nodata sentinels (-3.4028235e+38) at 3,073 pixels inside the scored footprint (measured band-by-band). Any model that does arithmetic over those pixels without masking can write ±inf/NaN or out-of-range values. Files produced by this project's shared writer are rejected at write-time unless the saved bytes re-read as finite [0,1] on the exact competition grid — DIPDUAL re-read: min 0.0, max 1.0, 0 NaN, 0 inf. Outside-footprint encoding here is 0.0 (-zeros); the reported 0.2778 B2 score is for a -zeros file, indicating zeros was accepted in that instance (unverified — confirm on the live page if unsure; the written spec says null or NaN outside bounds).
