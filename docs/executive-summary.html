WHY THE RELEASE IS STOPPED

The small print
that matters.

A valid raster is necessary, not sufficient. These constraints prevent an honest approval today.

01

No assigned lane

The protocol refers to a single method paragraph, but none is specified. No model was fit and no geological holdout was run.

02

A literal uniqueness conflict

In the independently checked mirror footprint, only 6,649 pixels lie farther than 3 pixels from the registered lattice. For 37,654 distinct dots, at least 31,005 must overlap: 82.3418%, above the 70% limit. This is a geometry bound, not a score. A smaller budget is not automatically valid.

03

Score estimate: Not estimable

Known-fault holdouts and expert-hidden faults are different populations. There is no validated mapping from a local holdout to leaderboard performance, and no score-to-file receipt in this checkout.

04

The format ambiguity remains

The official text says null/NaN outside bounds, while a strict whole-array range check rejects NaNs. All-finite alternatives may conflict with that text. We have not tested either encoding on the portal, and the mirrored sample is not organizer-authenticated.

WHEN A FUTURE FILE IS CLEARED

How to submit, step by step.

These instructions are for a future candidate that has passed all automated gates and a separate slot selector. There is no such file now.

01

Confirm the decision

Open the current run card. Verify the exact SHA-256, all feature canaries, matched holdout and both full-registry novelty checks. A format pass alone is not approval.

02

Download the approved TIFF

Use the enabled download link only after the release state explicitly says it is approved. Recheck the downloaded bytes against the displayed SHA-256.

03

Open DrivenData

Sign in to the GEMS competition, choose Submit, then Make new submission. Verify your actual weekly allowance there.

04

Upload & record

Select the single-band GeoTIFF, use the run card’s unique name and note of at most 140 characters, and retain the organizer receipt. Do not claim a score until it is received.
