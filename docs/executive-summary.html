STEP 4 — HOW TO SUBMIT (once a slot is selected)

Submission guide

These steps are instructions, not authorization. No file in this checkout holds an organizer receipt; the selector step (choosing a slot and checking the weekly allowance) is separate from building the file.

01

Verify the file

Re-open the downloaded TIF: single band, float32, EPSG:32611, 3730 × 3292, pinned transform (100, 0, 243350, 0, −100, 4508550), all values in [0,1] inside the footprint, zeros outside, no NaN inside. The local validator passed on every check (receipt beside the download).

02

Name and note

Use the exact file name and a note of at most 140 characters, e.g. Off-catalogue mag/gravity/topo/seismic edge dots, outside all registry halos; unique; research-only, not organizer-cleared. The note helps you tell submissions apart later (e.g. clustering with k=25).

03

Upload

Open DrivenData GEMS, select Submit → Make new submission, choose the single-band .tif or a ZIP containing one .tif, paste the note, and submit. The file must match the submission format's CRS, shape and geotransform.

04

Keep the receipt

Retain the organizer submission-page receipt (file-linked, with the score). A receipt is the only evidence that turns a local number into an organizer-confirmed score; nothing here is one.
