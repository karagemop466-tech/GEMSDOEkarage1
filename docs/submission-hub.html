HOW TO SUBMIT (WHEN A FILE IS CLEARED)

Step-by-step for the upload form

  1. Confirm the file's status on this page says CLEARED FOR UPLOAD. Right now every file says NOT CLEARED.
  2. Download the single .tif (or the one-TIFF .zip). Do not download from the registry copies; they are third-party copies, not this team's output.
  3. Check on your machine: one band, float32, EPSG:32611, shape 3730×3292, 100 m, identical transform to the sample, values in [0, 1] inside the footprint, NaN outside (public spec: "data outside the bounds is null or nan").
  4. Give it a unique name (≤ 140 characters) and a short note (≤ 140 characters) on the form, for example the name and note above.
  5. Use the official page for the rules: submission format and the official rules PDF. Three submissions per week; one final submission is selected before the deadline. The data tab is login-walled from this sandbox, and no upload was attempted.
